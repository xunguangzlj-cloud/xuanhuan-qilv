# 旋环奇旅

<img src="ui-art-1/brand-logo.png" alt="旋环奇旅" width="240">

旋转彩色圆环，对齐缺口，解开相扣的圆环。项目包含微信小游戏工程和电脑浏览器预览。

## 当前内容

- 400 个主线关卡，以及进度保存、关卡恢复和昼夜主题。
- 圆环拖动、滑杆及机关交互，提示、锤子和火箭等辅助道具。
- 首胜、宝箱和免费道具奖励。
- 音乐、音效与震动设置，三页动态教学。
- 微信好友排行，通过开放数据域展示同玩好友累计通关积分。

当前版本为 `0.8.4`。没有倒计时失败或按时间奖励计分。

## 电脑预览

需要 Node.js 22 或更新版本。

```sh
npm ci
npm run preview -- 4325
```

在浏览器打开命令输出的本地地址。预览启动前会自动构建；也可以单独运行 `npm run build`。浏览器预览使用本地存档，好友排行需要在微信环境运行。

## 微信开发者工具

1. 将仓库根目录导入微信开发者工具，项目类型选择“小游戏”。
2. 在 `project.config.json` 中将 `appid` 替换为自己有开发权限的小游戏 AppID。
3. 编译工程，检查模拟器，再生成微信预览。

仓库默认使用游客 AppID。真机预览、上传和发布需使用有权限的 AppID。启用好友排行时，还需在微信后台按实际用途配置用户隐私保护指引。

## 验证

```sh
npm test
npm run test:controller
```

检查涵盖设置开关、教学、存档、好友授权与开放域排序、微信打包依赖，以及控制器流程。

## 目录

| 目录或文件 | 内容 |
| --- | --- |
| `game.js`、`game.json` | 微信小游戏入口与分包配置 |
| `src/` | 玩法、渲染、交互、音频与界面逻辑 |
| `open-data/` | 微信好友排行开放数据域 |
| `assets/`、`packages/`、`ui-art-*/` | 界面、关卡、动画和运行资源 |
| `vendor/` | 本地运行依赖与许可 |
| `scripts/`、`tests/` | 浏览器构建与检查 |

第三方依赖的许可声明保留在 `vendor/` 和 `src/LICENSE-planck.txt` 中。
